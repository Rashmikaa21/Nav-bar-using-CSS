# Simple Navigation Bar Using CSS Flexbox

A simple navigation bar created using HTML and CSS, with a focus on using **CSS Flexbox** to arrange and align navigation items.

## 📌 Project Overview

This project demonstrates how to create a basic navigation bar using HTML and CSS. The main focus is on the `display: flex` property and its related Flexbox concepts.

## 📚 CSS Concepts Covered

- `display: flex`
- `justify-content`
- `align-items`
- `gap`
- `padding`
- `margin`
- `background-color`
- `color`
- `text-decoration`
- `:hover` pseudo-class

## 🛠️ Technologies Used

- HTML5
- CSS3
